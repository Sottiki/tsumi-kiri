# Tsumikiri タスク（tasks.md）

最終更新：2026-11-22
状態：**確定（2026-11-22）**

実装の段階と、それぞれの完了条件。1段階を1つの PR にする。各段階は「計画を確認 → 実装 → 確認」の順に進め、終わったタスクはその PR の中でチェックを付ける。

PR の確認項目は、コマンドで確かめられるもの（CI でも流す）と、人が見る項目に分けて書く。コマンドで確かめられることは、Vitest（`npm test`）か Playwright Test（`npm run test:e2e`）のテストにする。

画面の段階（4・6・9）の「画面案と並べて見比べる」は人が見る項目。Claude が Playwright MCP でスクショを撮って画面案と比べ、最後にユーザーが確認する。スクショは Google Fonts を読み込まずシステムの書体になるので、書体は見比べの対象にしない。

参照：仕様は SPEC.md、見た目は DESIGN.md、作り方は docs/architecture.md、検証例は docs/test-cases.md。
